# System Architecture

*[Return to Main README](README.md)*

`openas` exposes a uniform line-oriented and chunk-oriented streaming interface in both text (`str`, UTF-8 by default) and binary (`bytes`) modes over local files, remote network transports, and transparent stream compressors while keeping optional dependencies lazily imported.

## Stream Layering

```text
Caller (openas() / OpenAsReader / OpenAsWriter / CLI)
  |
  v
Target Resolution & Guards (_resolve_target, _validate_timeout, _validate_text_options, _validate_headers, _validate_key_filename, _validate_write_options)
  |-- rejects container archives (.zip, .tar.*, .7z, .rar, ...)
  |-- rejects cloud schemes (s3://, gs://, az://, hdfs://) and unknown scheme://
  |-- rejects HTTP/HTTPS writes and FTP append
  |-- validates text options (encoding/errors/newline), headers, key_filename, compresslevel & imports codec before moving existing files to .bu backups
  v
Transport Layer (_wrap_local, _wrap_http, _wrap_ftp, _wrap_ssh)
  |-- Local: plain file / atomic os.link+os.unlink sequential .bu backups
  |-- HTTP/HTTPS: thread-local cookie-free requests.Session + per-request headers + _HttpRawStream
  |-- FTP: ftputil.FTPHost + FTPSessionWrapper + _BinaryStreamAdapter
  |-- SSH/SFTP: paramiko.SSHClient (system host keys + optional key_filename) + _BoundedSFTPReadStream (4 MiB readv windows) / SFTPFile + _BinaryStreamAdapter
  v
Optional Raw-Byte Counter (_CountingByteStream on reads, _CountingWriteStream on writes: 64 KiB batched tqdm.update when show_progress=True)
  v
Zstandard Frame Validator (.zst reads only: _ZstdFrameValidatingStream, zero-copy RFC 8878 boundary check raising EOFError on truncation)
  v
Codec Layer (.gz, .bz2, .xz, .zst via ZstdDecompressor.stream_reader with 128 KiB read_size, or uncompressed)
  v
Mode Layer:
  |-- Text mode (default): io.TextIOWrapper / io.TextIOBase (configurable encoding/errors/newline, UTF-8 default; .zst buffered at 128 KiB)
  |-- Binary mode (rb/wb/ab, binary=True): io.BufferedReader (64 KiB / 128 KiB for .zst) / binary codec / _BinaryStreamAdapter (raw bytes; OpenAsReader.flush/read1 compose with io.TextIOWrapper)
```

## Core Components

### 1. Routing Facade (`openas()`)

`openas()` maps modes to `OpenAsReader` (`'r'`/`'rt'` with `binary=False`; `'rb'` with `binary=True`) or `OpenAsWriter` (`'w'`/`'wt'` with `append=False, binary=False`; `'wb'` with `append=False, binary=True`; `'a'`/`'at'` with `append=True, binary=False`; `'ab'` with `append=True, binary=True`), forwarding `backup`, `show_progress`, optional `compresslevel`, optional `timeout`, text options (`encoding`, `errors`, `newline`), optional HTTP `headers` (validated unconditionally in `openas()`, forwarded to `OpenAsReader` only), and optional SSH `key_filename`.

Optional standard library modules (`argparse`, `atexit`, `bz2`, `ftplib`, `gzip`, `lzma`, `math`, `urllib.parse`, `urllib.request`, `weakref`) and third-party packages (`paramiko`, `ftputil`, `requests`, `zstandard`, `tqdm`) are imported lazily on first use. Top-level `openas.__all__` exports only the public API (`openas`, `OpenAsReader`, `OpenAsWriter`, custom exceptions, `__version__`, and `__author__`); internal `FTPSessionWrapper` remains lazily accessible on `openas.openas` via PEP 562 `__getattr__`.

### 2. Target Resolution and Safety Guards

`_resolve_target()` requires a leading `scheme://` prefix (`'://'` present and `filename.lower().startswith(f"{scheme}://")`) before treating a target as a URL, parsing URLs with `urllib.parse.urlsplit()` so semicolons remain part of `parsed.path`. Plain local paths and single-colon local filenames (such as `file:report.txt`) remain local without URL parsing:

- `file://` URIs are accepted only with an empty host or `localhost` (no userinfo) and a non-empty path, converted via `urllib.request.url2pathname` (decoding percent-encoded paths). Rejected `file://` authorities redact credentials via `urlsplit(_redact_url(filename)).netloc`; empty paths raise `ValueError`.
- Cloud object store schemes (`s3://`, `gs://`, `az://`, `hdfs://`) and unrecognized multi-letter `scheme://` URLs raise `UnsupportedProtocolError`.
- Supported remote URLs (`http`, `https`, `ftp`, `ssh`, `sftp`) require a non-empty hostname and a valid port in `1..65535` (raising redacted `ValueError` without echoing raw port/password substrings). Empty paths raise `ValueError` on `ftp://`, `ssh://`, and `sftp://` while remaining allowed on `http://` and `https://`. FTP and SSH/SFTP credentials and paths are percent-decoded via `urllib.parse.unquote`.
- `_normalized_path()` percent-decodes network URL paths via `urllib.parse.unquote(parsed.path).lower()` (ignoring query strings) before case-insensitive extension and container-archive (`UNSUPPORTED_ARCHIVES`) checks, rejecting container archives with `UnsupportedArchiveError`.
- `_redact_url()` masks URL userinfo passwords, non-numeric port suffixes (including malformed no-`@` URLs such as `sftp://user:secret:1234/file.txt` and bracketed IPv6 non-numeric port suffixes), and query parameters before printing in CLI output/errors, `__repr__()`, or error messages.

### 3. Transport Wrappers

- **Local (`_wrap_local`, `_backup_local_file`):** Validates `compresslevel` and imports optional codecs before touching disk. Sequential `.bu` backup handling checks `<path>.001.bu` first in O(1); if occupied, it scans the parent directory once via `os.scandir` to find the lowest free 3-digit ASCII slot up to `.999.bu`, then falls back to nanosecond timestamps (`time.time_ns()`). Existing directories raise `IsADirectoryError` rather than being renamed. Moves use `os.link(..., follow_symlinks=False)` + `os.unlink()` when `os.link in os.supports_follow_symlinks`, or check `os.path.islink(src)` first and use collision-checked `os.rename()` (checking `os.path.lexists(dst)`) when `follow_symlinks=False` is unavailable or unsupported, so broken and valid symlinks move as symlinks without following or hard-linking their targets.
- **SSH / SFTP (`_wrap_ssh`, `_BoundedSFTPReadStream`, `_ssh_backup_if`):** Uses `paramiko.SSHClient()` with `load_system_host_keys()` and Paramiko's default `RejectPolicy`, forwarding optional validated `key_filename` (omitted when `None`) and `timeout` (`timeout`, `banner_timeout`, `auth_timeout`) to `connect()` and propagating `timeout` to `sftp.get_channel().settimeout(timeout)` when available. Assigns `self._ssh_client` before `connect()` so host-key or authentication failures close the transport thread cleanly. Reads record `stat().st_size` once in `_sftp_file_size`. When `file_size > 0` and `sftp_file.readv` is available, `_wrap_ssh()` wraps `SFTPFile` in `_BoundedSFTPReadStream` (stored on `self._raw_fh` for deterministic teardown under codecs like `GzipFile` that do not close wrapped `fileobj` handles), requesting 4 MiB sliding windows split into `MAX_REQUEST_SIZE` sub-chunks via `readv(sub_chunks, max_concurrent_prefetch_requests=64)` (with Paramiko `<3.3` `TypeError` fallback and early-EOF stop on truncated files). When `readv` is absent or `file_size` is unknown or non-positive, reads fall back to sequential `sftp_file.read()` (wrapped in `_BinaryStreamAdapter` + `io.BufferedReader` for plain binary mode). Writes open SFTP files in binary mode (`'wb'`/`'ab'`), enable `set_pipelined(True)`, and wrap uncompressed streams in `_BinaryStreamAdapter` (and `io.TextIOWrapper` in text mode) so `write()` consistently returns `int`. Before creating an SFTP `.bu` backup, `OpenAsWriter._ssh_backup_if()` checks `sftp.stat(path).st_mode` with `stat.S_ISDIR` and raises `IsADirectoryError` for existing remote directories instead of renaming them, and retries `rename()` collisions across free slots.
- **FTP (`_wrap_ftp`, `FTPSessionWrapper`):** Uses `ftputil.FTPHost` with `FTPSessionWrapper` (default port 21, custom ports and optional `timeout` forwarded, socket closed if `login()` fails). Wraps `ftputil.file.FTPFile` in `_BinaryStreamAdapter(io.BufferedIOBase)` so `io.TextIOWrapper`, `io.BufferedReader`, `bz2.open`, `lzma.open`, and direct binary writes work reliably on real FTP handles. When `backup=True` and the remote target exists, `OpenAsWriter._wrap_ftp()` checks `self._ftp.path.isdir(remote_path)` and raises `IsADirectoryError` for existing remote directories; otherwise it moves existing files to sequential `.bu` backups (checking `.001.bu` first in O(1), then scanning the parent directory once with `listdir()` up to `.999.bu` with a nanosecond timestamp fallback). FTP append mode is rejected up front with `UnsupportedProtocolError`.
- **HTTP / HTTPS (`_wrap_http`, `_get_http_session`):** Reuses a lock-initialized, thread-local `requests.Session` stored inside `_HttpSessionHolder` on `threading.local()` with cookie persistence disabled (`DefaultCookiePolicy(allowed_domains=[])`). Registers a lazy `weakref.finalize` (`atexit=False`) on each holder so exited worker threads remove and close their session under `_http_session_lock` without double-closing against `atexit` `_close_registered_http_sessions`. Copies validated `headers` into a fresh per-request `dict` (never mutating caller mappings or `session.headers`) and adds `Accept-Encoding: identity` on compressed extensions unless the caller supplies an `Accept-Encoding` header (checked case-insensitively) so servers do not double-encode compressed bodies. On uncompressed responses, enables `response.raw.decode_content = True`, streams through `_HttpRawStream(response.raw)` into `io.TextIOWrapper` (text) or `io.BufferedReader` (binary), and sets `_http_file_size = None` when `Content-Encoding` is present so progress bars do not compare compressed `Content-Length` against decompressed bytes.

### 4. Hot Paths, Progress Accounting, Handle Teardown, and CLI

- **Iteration, `readlines()`, `read1()`, and Write Hot Paths:** `OpenAsReader.__iter__()` returns the underlying C-level iterator (`io.TextIOBase` in text mode, or `io.BufferedReader` in binary mode) directly when `show_progress=False` or when `_CountingByteStream` owns progress updates (all compressed and remote streams). Binary `.gz`, `.bz2`, `.xz`, and plain network readers wrap their handle in `io.BufferedReader(..., buffer_size=65536)` for C-level newline scanning; `.zst` readers (`OpenAsReader._open_zst_reader()`) wrap the raw or `_CountingByteStream`-wrapped stream in `_ZstdFrameValidatingStream` (zero-copy RFC 8878 frame-boundary validation that raises `EOFError` on truncated streams) before `ZstdDecompressor.stream_reader(..., read_across_frames=True, read_size=131072)` and `io.BufferedReader(..., buffer_size=131072)` in both text and binary modes. `OpenAsReader.flush()` (no-op when open, `ValueError` when closed) and binary-only `OpenAsReader.read1(size=-1)` (`io.UnsupportedOperation` in text mode) enable direct `io.TextIOWrapper(openas(path, "rb"))` composition. All stream adapter `readinto()` methods (`_BinaryStreamAdapter`, `_HttpRawStream`, `_BoundedSFTPReadStream`, `_CountingByteStream`, and `_ZstdFrameValidatingStream`, plus `_ZstdFrameValidatingStream._feed()`) use context-managed `memoryview(...).cast('B')` byte views for typed-buffer safety. `OpenAsReader.readlines(hint=-1)` delegates directly to C-level `self._fh.readlines()` / `self._fh.readlines(hint)` for non-progress and counted streams (using `list(self._iter_progress())` for unbounded plain local progress reads). When `OpenAsWriter.write` is not overridden by a subclass, `OpenAsWriter.open()` binds `self.write` directly to `self._fh.write` (removed on `close()`). In binary mode, `OpenAsWriter.writelines()` iterates `self._fh.write(line)` so `ZstdCompressionWriter` behaves identically to stdlib binary writers.
- **Progress Accounting:** Compressed and remote read streams wrap their binary handle in `_CountingByteStream`, which is the sole progress owner for counted reads: `OpenAsReader.open()` attaches `self._progress.update` after initializing `tqdm(initial=initial_bytes)` so `open()` header bytes are never double-counted, and `_CountingByteStream` batches `tqdm.update()` in 64 KiB increments while flushing exact remainders at EOF (before `close()`), on `readline()`/`read()`/`read1()`/`readlines()`, and in `close()`. Uncompressed local reads use `_iter_progress()` to count encoded byte length in text mode (`_encoded_byte_len()` using a cached incremental encoder for BOM encodings `utf-16`/`utf-32`/`utf-8-sig`, `self._encoding` and `self._errors or 'strict'` with safe `'replace'` fallback for lossy text, total clamping for BOM and lossy error handlers, plus natural-EOF reconciliation for CRLF universal newlines, BOM encodings, and lossy error handlers) and raw byte length in binary mode (`len(line)`). When file size is unavailable or `stat()`/`getsize()` fails, `tqdm` uses `total=None`. For writes (`OpenAsWriter(show_progress=True)`), `_CountingWriteStream(io.BufferedIOBase)` wraps the underlying binary write stream across local, FTP, and SFTP writers (adding zero overhead when `show_progress=False`), normalizes any bytes-like buffer via `memoryview(b).cast('B')`, accounts exact raw bytes written (treating `None` returns from Paramiko `SFTPFile` or mocks as `len(data)` and returning `int`), batches `tqdm.update()` at 64 KiB, and flushes pending deltas on `flush()` and `flush_progress()`. `OpenAsWriter.open()` initializes `tqdm(total=None, initial=initial_bytes, unit='B', unit_scale=True)` after wrapping the codec so header bytes written during `open()` are captured in `initial` without loss or double-counting.
- **Deterministic Teardown:** `OpenAsReader.close()` flushes pending progress (catching `BaseException`), detaches `_CountingByteStream` callbacks, snapshots and clears all handle attributes, and invokes `_close_handles()` (preserving any primary flush error even if a handle close raises `BaseException`). `OpenAsWriter.close()` closes `self._fh` FIRST while the progress callback is active (so `io.TextIOWrapper` and compressors flush buffered payload and compressed trailer bytes through `_CountingWriteStream`), then flushes any remaining batched progress delta (catching `BaseException`), detaches the callback, and closes remaining handles (`_counting_stream`, `_raw_fh`, transport handles, and `tqdm`) via `_close_handles()`, preserving the first error across all steps. Zstandard `stream_reader()` and `stream_writer()` are created with `closefd=False`, and FTP wrappers store their `_BinaryStreamAdapter` in `self._raw_fh` so `_close_handles()` owns single-close teardown deterministically without GC finalizer re-closing. `_close_handles()` catches `BaseException` around each handle's `close()`, calls `_record_raw_close_attempted()` (traversing `_CountingWriteStream`, `_CountingByteStream`, `_ZstdFrameValidatingStream`, and `io.IOBase` `.buffer`/`.raw` wrappers to deduplicate underlying raw handles already closed by `_CountingWriteStream`, `_BinaryStreamAdapter`, or `_BoundedSFTPReadStream`), closes all remaining handles, and re-raises the first error. Mid-`open()` cleanup also catches `BaseException` so interrupts (`KeyboardInterrupt`) do not leak sockets or threads.
- **CLI (`main()`, `_cli_main()`, `src/openas/__main__.py`):** Exposed via `openas`, `python -m openas`, and `python -m openas.openas`. `_cli_main()` wraps `main()`, classifies expected operational failures via `_is_cli_operational_error()` (`OpenAsError`, `OSError`, `EOFError`, `ValueError`, `LookupError`, and codec/transport module errors including `bz2`, `lzma`, `zlib`, `zstandard`, `ftplib`, `ftputil`, `paramiko`, `requests`, `urllib3`, and `http`), redacts embedded URLs via `_redact_urls_in_text()`, prints `openas: error (<ExcName>): <message>` to `stderr`, and exits 1 without a traceback while letting unexpected internal errors and `KeyboardInterrupt` propagate. Both `--read` and `--write` stream 64 KiB binary chunks (`OpenAsReader(..., binary=True)` / `OpenAsWriter(..., binary=True)`), preserving exact bytes (including CRLF and non-UTF-8 payloads) and counting `b'\n'`-delimited lines. Supports `--no-backup` (disables `.bu` rotation on `--write`; rejected on `--read`), `--compresslevel` / `-c` (pre-validated per destination via `_validate_write_options()`; rejected on `--read`), `--timeout` (pre-validated via `_validate_timeout()` and forwarded to both reader and writers), and `--progress` (forwards `show_progress=True` to `OpenAsReader` on `--read` and to the source `OpenAsReader` on `--write`, rendering progress on `stderr`). `--write` pre-validates timeout, destination schemes, archive guards, read-only protocols, compression levels, existing non-symlink local directories (`IsADirectoryError`), source-equals-destination aliasing (including symlink `realpath` aliasing under `--no-backup`), and canonical duplicate destinations (including `--no-backup` symlink target collisions) via `parser.error` exit 2 with redacted URLs before opening streams, reads the source once inside `contextlib.ExitStack` (opening destinations with `OpenAsWriter(...).open(append=False, backup=not args.no_backup, compresslevel=args.compresslevel)`), and fans chunks out synchronously to all destinations.

## Test and Benchmark Layout

- **Unit tests (`tests/unit/`):**
  - `test_local_io.py`: Local codecs (text and binary modes), multi-chunk line streaming, sequential `.bu` backups, progress accounting, `file://` URIs, truncated and corrupt compressed stream checks (including `.zst` `EOFError` without resource warnings), O(1) `tracemalloc` streaming memory-bound tests, `KeyboardInterrupt` mid-open cleanup tests, lifecycle, lazy imports, and file-like attributes.
  - `test_routing.py`: Mocked FTP/SFTP/HTTP routing (text and binary modes), bounded 4 MiB SFTP `readv()` multi-window/early-break/truncation tests, remote truncated `.zst` `EOFError` checks across HTTP, FTP, and SFTP, remote `KeyboardInterrupt` mid-open cleanup tests, real `FTPFile`-contract tests, `FTPSessionWrapper`, percent-decoding, timeouts, and an ephemeral local `ThreadingHTTPServer` for cookie-free and gzip HTTP streaming.
  - `test_guards.py`: Archive guards, protocol guards, invalid modes, append/backup conflicts, and text vs binary mode contracts.
- **Regression tests (`tests/regression/`):**
  - `test_golden.py`: Reads and round-trip verifies `tests/fixtures/gold.txt`, `gold.txt.gz`, `gold.txt.bz2`, `gold.txt.xz`, and `gold.txt.zst` in both text and binary modes against independent stdlib and `zstandard` decoders.
  - `test_cli.py`: CLI flags, single-pass broadcast, error exits, credential redaction, and checkout `src/` import verification.
- **Benchmarks (`benchmarks/bench_openas.py`):** Standalone informational suite measuring nine workloads: import latency, 200k-line text read throughput, 200k-line write throughput, compression peak RSS, local HTTP throughput, 500-backup allocation latency, 3-target CLI broadcast, 200k-line binary (`'rb'`) read throughput, and 200k-line `OpenAsReader.readlines()` throughput.
