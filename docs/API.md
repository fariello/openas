# Public API Reference: `openas`

*[Return to Main README](../README.md)*

Formal Python API reference for `openas` v0.1.0.

## Unified Entry Point

### `openas(filename, mode='r', backup=None, show_progress=False, compresslevel=None, timeout=None, encoding=None, errors=None, newline=None, headers=None, key_filename=None) -> Union[OpenAsReader, OpenAsWriter]`

Opens a local or remote stream with transparent compression in text (`str`, UTF-8 by default) or binary (`bytes`) mode and returns an opened `OpenAsReader` or `OpenAsWriter` context manager.

#### Parameters

- **`filename`** (`Union[str, os.PathLike]`): Target path or URL (for example `tests/data.txt`, `pathlib.Path("data.gz")`, `https://example.com/log.zst`, `ftp://user@host/path/to/data.txt`, or `sftp://user@host/path/to/syslog.zst`). Targets are treated as URLs only when they start with `scheme://`; single-colon local filenames such as `file:report.txt` remain local paths. Query strings are ignored when detecting extensions, extension matching is case-insensitive, FTP/SSH/SFTP credentials and paths are percent-decoded, and network URL paths are percent-decoded before extension and archive checks (so `https://example.com/data%2Egz` is read as `.gz` and `https://example.com/archive%2Ezip` raises `UnsupportedArchiveError`). `file://` URIs require an empty host or `localhost`.
- **`mode`** (`str`, default `'r'`):
  - Text read (`'r'`, `'rt'`): opens `OpenAsReader(..., binary=False)` returning decoded `str` (UTF-8 by default).
  - Binary read (`'rb'`): opens `OpenAsReader(..., binary=True)` returning raw `bytes`.
  - Text write / truncate (`'w'`, `'wt'`): opens `OpenAsWriter(..., binary=False).open(append=False, ...)` accepting `str` (UTF-8 by default).
  - Binary write / truncate (`'wb'`): opens `OpenAsWriter(..., binary=True).open(append=False, ...)` accepting `bytes`-like objects.
  - Text append (`'a'`, `'at'`): opens `OpenAsWriter(..., binary=False).open(append=True, ...)` accepting `str` (UTF-8 by default).
  - Binary append (`'ab'`): opens `OpenAsWriter(..., binary=True).open(append=True, ...)` accepting `bytes`-like objects.
  - Any other mode raises `ValueError`.
- **`backup`** (`Optional[bool]`, default `None`): Moves an existing target to a sequential `.bu` backup before overwriting locally or over SSH/SFTP/FTP. Checks `<path>.001.bu` first in O(1); if occupied, lists the parent directory once (`os.scandir` locally, single `listdir` on SFTP/FTP) to pick the lowest free slot (`.001.bu`..`.999.bu`), falling back to nanosecond timestamps (`time.time_ns()`) past 999. Resolves to `True` in write modes and `False` in append modes. Passing `backup=True` with append raises `ValueError`.
- **`show_progress`** (`bool`, default `False`): Enables a `tqdm` progress bar tracking exact raw bytes read (`OpenAsReader`) or written (`OpenAsWriter`). On `OpenAsReader`, updates are batched at 64 KiB with exact remainder flush on EOF, early exit, and `close()`, falling back to `total=None` when stream size is unavailable; for uncompressed local text files with `newline=None` and CRLF (`\r\n`) or CR (`\r`) line endings, `OpenAsReader` reconciles the bar to `total` at natural EOF (`_reconcile_crlf_eof_progress()`), skipped when `newline` is explicitly set. On `OpenAsWriter` (write and append modes), `_CountingWriteStream` wraps the underlying binary target handle across local, FTP, and SFTP streams with `total=None`, capturing codec header bytes written during `open()` in `initial`, batching `tqdm.update()` at 64 KiB, and flushing buffered payload and compressed trailer bytes on `flush()` and `close()`. When `show_progress=False`, `OpenAsWriter` adds zero wrapper overhead.
- **`compresslevel`** (`Optional[int]`, default `None`): Optional compression level or preset forwarded to write/append codecs (ignored on read). Validated by `_validate_write_options()` before creating any `.bu` backup (`bool` or non-`int` values raise `TypeError`; out-of-range integers raise `ValueError`). Accepted ranges and defaults when `None`:
  - `.gz`: integers `0` through `9` (default `9`).
  - `.bz2`: integers `1` through `9` (default `9`).
  - `.xz`: integers `0` through `9`, optionally bitwise-OR'd with `lzma.PRESET_EXTREME` (default `6`).
  - `.zst`: integers up to `zstandard.MAX_COMPRESSION_LEVEL` (`22`, including negative fast levels), validated via `zstandard.ZstdCompressor(level=compresslevel)` (default `3`).
  - Plain (uncompressed) files: type-checked as `int` (rejecting `bool` and non-integers with `TypeError`), then ignored.
- **`timeout`** (`Optional[float]`, default `None`): Optional finite positive timeout in seconds forwarded to HTTP (`requests.Session.get`), SSH/SFTP (`timeout`, `banner_timeout`, `auth_timeout`), and FTP (`connect`). Non-positive, non-finite (`nan`, `inf`, `-inf`), or boolean values raise `ValueError`.
- **`encoding`** (`Optional[str]`, default `None`): Text codec name matching `builtins.open()` semantics. In text modes, `None` defaults to `'utf-8'`, and non-`None` values are validated via `codecs.lookup()` in `__init__()` before creating any `.bu` backup or opening a transport (non-`str` raises `TypeError`; unknown codecs raise `LookupError`). In binary modes (`'rb'`, `'wb'`, `'ab'`), any non-`None` value raises `ValueError`.
- **`errors`** (`Optional[str]`, default `None`): Text codec error handler (for example `'strict'`, `'replace'`, `'ignore'`, or `'surrogateescape'`). In text modes, `None` uses Python's default (`'strict'`), and non-`str` values raise `TypeError` before any backup or transport open. In binary modes, any non-`None` value raises `ValueError`.
- **`newline`** (`Optional[str]`, default `None`): Newline translation mode matching `builtins.open()`, accepting `None`, `""`, `"\n"`, `"\r"`, or `"\r\n"` across all local and remote text streams. When `None` (default), reads apply universal newline translation to `\n` and writes translate `\n` to `os.linesep` (`\n` on POSIX, `\r\n` on Windows). Pass `newline=""` for `csv.reader`/`csv.writer` or `newline="\n"` to write LF bytes on every platform. Validated before any backup or transport open (non-`str` raises `TypeError`; invalid strings raise `ValueError`). In binary modes, any non-`None` value raises `ValueError`.
- **`headers`** (`Optional[Mapping[str, str]]`, default `None`): Optional per-request HTTP/HTTPS headers (for example `Authorization` or `User-Agent`). Validated unconditionally by `openas()` (including on write/append modes before any `.bu` backup): non-`Mapping` values and non-`str` keys or values raise `TypeError`; empty or whitespace-only header names and CR (`\r`), LF (`\n`), or NUL (`\x00`) characters in names or values raise `ValueError` without interpolating header values into exception messages. Valid `headers` are ignored on non-HTTP targets and write/append modes. Stored as a defensive copy and merged into a fresh per-request `dict` (never mutating the caller's mapping or the thread-local `requests.Session.headers`). Compressed HTTP/HTTPS URLs keep `Accept-Encoding: identity` unless the caller supplies an `Accept-Encoding` header (checked case-insensitively). Header names and values are never exposed in `__repr__()`. **Cross-host redirect note:** `requests` strips `Authorization` headers when following cross-host redirects (`Session.rebuild_auth`), while other custom headers (such as `X-API-Key`) are forwarded across redirects by `requests`.
- **`key_filename`** (`Optional[Union[str, os.PathLike, Sequence[Union[str, os.PathLike]]]]`, default `None`): Optional SSH private key path or non-empty sequence of key paths forwarded to `paramiko.SSHClient.connect(key_filename=...)` for `ssh://` and `sftp://` targets (omitted from `connect()` kwargs when `None`). Validated and normalized via `os.fsdecode()` in `__init__()` before any `.bu` backup or network connection: `bytes`, `bytearray`, and non-path types raise `TypeError`; empty paths and empty sequences raise `ValueError`. Omitted from `__repr__()`.

#### Remote URL Paths, Authentication, and Environment Variables

- **SSH / SFTP (`ssh://`, `sftp://`):** `urllib.parse.urlsplit(url).path` (percent-decoded via `urllib.parse.unquote()`, preserving semicolons) must be non-empty and is passed directly as an absolute remote path (for example `sftp://user@host/path/to/syslog.zst` opens `/path/to/syslog.zst`). Tilde (`~/`) home-directory expansion is not performed. Paramiko connects directly via `SSHClient.connect()` and does not read `~/.ssh/config` host aliases or options. When the URL omits a username, Paramiko defaults to the local OS user and authenticates via the SSH agent, default `~/.ssh/id_*` keys, or any key path(s) supplied through `key_filename`.
- **FTP (`ftp://`):** The percent-decoded `urlsplit(url).path` (preserving semicolons) must be non-empty and is passed directly to `ftputil.FTPHost.open()`. When the URL omits credentials, `ftplib.FTP.login(None, None)` logs in anonymously.
- **Environment variables:** `openas` defines no custom environment variables. HTTP/HTTPS requests reuse `requests.Session()` with default `trust_env=True`, so HTTP/HTTPS honors standard `requests` environment settings (`HTTP_PROXY`, `HTTPS_PROXY`, `NO_PROXY`, `REQUESTS_CA_BUNDLE`, `CURL_CA_BUNDLE`, and `~/.netrc` credentials).

#### Exceptions

All custom exceptions inherit from `OpenAsError`:

- `UnsupportedArchiveError`: Raised when the normalized path matches a container archive extension (`.zip`, `.tar`, `.tgz`, `.rar`, `.7z`, `.tar.gz`, `.tar.bz2`, `.tar.xz`, `.tar.zst`, `.tar.lzma`, `.tbz`, `.tbz2`, `.txz`, `.tzst`, `.tlz`, `.gz.tar`, `.bz2.tar`, `.xz.tar`, `.zst.tar`), including URLs with query strings or semicolons in filenames. URL credentials and query strings are redacted in the error message.
- `ReadOnlyProtocolError`: Raised when writing or appending to `http://` or `https://`.
- `UnsupportedProtocolError`: Raised for cloud object stores (`s3://`, `gs://`, `az://`, `hdfs://`), unknown `scheme://` URLs, non-localhost or userinfo-bearing `file://` authorities (with credentials redacted), and FTP append mode.
- Standard exceptions: `FileNotFoundError` for missing files/SFTP targets, `IsADirectoryError` when attempting a local, SFTP, or FTP `.bu` backup on an existing directory, `EOFError` when reading truncated `.zst` streams across local, HTTP, FTP, and SFTP transports (detected by `_ZstdFrameValidatingStream` before frame completion), `LookupError` when `encoding` names an unknown codec, `io.UnsupportedOperation` when calling `OpenAsReader.read1()` in text mode, `TypeError` when writing `bytes` to a text writer, writing `str` to a binary writer, or passing invalid types for `compresslevel`, `encoding`, `errors`, `newline`, `headers`, or `key_filename`, `requests.HTTPError` for HTTP 4xx/5xx responses (response closed before re-raising), and `ValueError` for invalid modes, text options passed in binary mode, invalid `newline` strings, empty or CR/LF/NUL-bearing HTTP headers, empty `key_filename` values, missing URL hostnames, invalid or zero URL ports (outside `1..65535`, with credentials redacted), empty paths on `file://`/`ftp://`/`ssh://`/`sftp://` URLs, `append=True` + `backup=True`, non-positive or non-finite `timeout`, out-of-range `compresslevel`, or operations on closed handles.

## Direct Handler Classes

### `class OpenAsReader`

Reads local and remote (`ftp://`, `ssh://`, `sftp://`, `http://`, `https://`) streams line-by-line or in chunks with transparent `.gz`, `.bz2`, `.xz`, and multi-frame `.zst` decompression. Operates on decoded `str` (UTF-8 by default) or raw `bytes` when `binary=True`.

#### Properties and Methods

- **`__init__(self, filename: Union[str, os.PathLike], show_progress: bool = False, timeout: Optional[float] = None, binary: bool = False, encoding: Optional[str] = None, errors: Optional[str] = None, newline: Optional[str] = None, headers: Optional[Mapping[str, str]] = None, key_filename: Optional[Union[str, os.PathLike, Sequence[Union[str, os.PathLike]]]] = None)`**: Normalizes `PathLike` inputs via `os.fsdecode()` and validates `timeout`, text options, `headers`, and `key_filename`.
- **`binary` (`bool`)**, **`closed` (`bool`)**, **`encoding` (effective encoding string in text mode, default `'utf-8'`, or `None` in binary mode)**, **`readable() -> True`**, **`writable() -> False`**, **`seekable() -> False`**, **`__repr__() -> str`** (includes `mode` and redacts URL credentials/queries; omits `headers` and `key_filename`).
- **`open(self) -> OpenAsReader`**: Opens the transport and codec stream:
  - FTP defaults to port 21, forwards custom ports and `timeout`, and wraps `ftputil.file.FTPFile` in an `io.BufferedIOBase` adapter.
  - SSH/SFTP defaults to port 22, verifies system host keys (`load_system_host_keys()` + `RejectPolicy`), forwards `key_filename` when set, caches `stat().st_size` once, and wraps `SFTPFile` in a bounded 4 MiB sliding-window `readv()` stream (`MAX_REQUEST_SIZE` sub-chunks, `max_concurrent_prefetch_requests=64`, Paramiko `<3.3` fallback) when `readv` is available and size is positive, guaranteeing O(1) memory on multi-GB files. When `readv` is absent or size is unknown or non-positive, it falls back directly to sequential `sftp_file.read()`.
  - HTTP/HTTPS reuses a lock-initialized, thread-local, cookie-free `requests.Session` (automatically closed and deregistered via `weakref.finalize` when a worker thread exits, with `atexit` cleanup for remaining sessions), builds a fresh per-request headers dict preserving `Accept-Encoding: identity` for compressed extensions unless overridden case-insensitively, validates status via `raise_for_status()`, enables `response.raw.decode_content = True` strictly on uncompressed responses, and sets `total=None` if `Content-Encoding` is set on uncompressed responses.
  - Binary compressed readers (`.gz`, `.bz2`, `.xz`) and plain binary network readers are wrapped in `io.BufferedReader(..., buffer_size=65536)` for fast C-level line scanning across chunk boundaries; `.zst` readers wrap the raw binary stream in `_ZstdFrameValidatingStream` (zero-copy RFC 8878 frame validation raising `EOFError` on truncated streams) before `ZstdDecompressor.stream_reader(..., read_across_frames=True, read_size=131072)` and `io.BufferedReader(..., buffer_size=131072)` in both text and binary modes.
  - Reopening after `close()` works cleanly.
- **`read(size=-1) -> Union[str, bytes]`**, **`read1(size=-1) -> bytes`**, **`readline(size=-1) -> Union[str, bytes]`**, **`readlines(hint=-1) -> list`**, **`flush() -> None`**, **`__iter__()`**, **`__next__() -> Union[str, bytes]`**: Standard stream read operations (`str` when `binary=False`, `bytes` when `binary=True`). All raise `ValueError` on a closed reader. `flush()` is a safe no-op when open, and `read1(size=-1)` is binary-only (raising `io.UnsupportedOperation` in text mode, updating progress tracking, and falling back to `self._fh.read()` if the underlying stream lacks `read1()`). Together, `flush()` and `read1()` allow binary readers to compose directly with `io.TextIOWrapper(openas(path, "rb"), ...)` without `AttributeError` or `ResourceWarning`. `readlines(hint=-1)` loads all remaining lines into a list when `hint` is `None` or `<= 0`, or stops once cumulative line length reaches or exceeds `hint` when `hint > 0` (delegating directly to C-level `self._fh.readlines()` for non-progress and `_CountingByteStream` streams). On multi-GB files, iterate line-by-line (`for line in reader:`) or read bounded chunks (`reader.read(65536)`) instead of calling unbounded `readlines()` or `read()` to stay in O(1) memory.
- **`close() -> None`**: Deterministically and idempotently closes all acquired handles and resets state, even if progress flushing or a handle close raises an `Exception` or `BaseException` (such as `KeyboardInterrupt`).

### `class OpenAsWriter`

Writes local and remote (`ftp://`, `ssh://`, `sftp://`) streams with transparent `.gz`, `.bz2`, `.xz`, and `.zst` compression and optional sequential `.bu` backups. Operates on encoded `str` (UTF-8 by default) or raw `bytes`-like objects when `binary=True`.

> **Context-manager options note:** `with OpenAsWriter(path) as w:` calls `open()` with defaults (`append=False, backup=True, compresslevel=None`). To pass custom options with a `with` statement, chain `with OpenAsWriter(path).open(append=..., backup=..., compresslevel=...) as w:` or use `openas(...)`.

#### Properties and Methods

- **`__init__(self, filename: Union[str, os.PathLike], show_progress: bool = False, timeout: Optional[float] = None, binary: bool = False, encoding: Optional[str] = None, errors: Optional[str] = None, newline: Optional[str] = None, key_filename: Optional[Union[str, os.PathLike, Sequence[Union[str, os.PathLike]]]] = None)`**: Normalizes `PathLike` inputs; accepts `show_progress=True` for raw-byte `tqdm` progress tracking across plain and compressed local, FTP, and SFTP writes/appends; validates `timeout`, text options (`encoding`, `errors`, `newline`), and `key_filename` before any `.bu` backup or connection. Does not accept `headers` because HTTP/HTTPS is read-only.
- **`binary` (`bool`)**, **`show_progress` (`bool`)**, **`closed` (`bool`)**, **`encoding` (effective encoding string in text mode, default `'utf-8'`, or `None` in binary mode)**, **`readable() -> False`**, **`writable() -> True`**, **`seekable() -> False`**, **`__repr__() -> str`** (includes `mode` and redacts URL credentials/queries; omits `key_filename`).
- **`open(self, append: bool = False, backup: bool = True, compresslevel: Optional[int] = None) -> OpenAsWriter`**: Validates `compresslevel` and imports required codecs before moving an existing file to a `.bu` backup or opening the target. Local, SFTP, and FTP `.bu` backups reject existing directories with `IsADirectoryError` without renaming them. Local backups use `os.link(..., follow_symlinks=False)` + `os.unlink()` when supported (or collision-checked `os.rename()` for symlinks otherwise), moving both broken and valid local symlinks as symlinks without following, creating, or hard-linking their targets. SFTP forwards `key_filename` when set, opens binary mode (`'wb'`/`'ab'`) with `set_pipelined(True)`, and wraps uncompressed writes in `_BinaryStreamAdapter` (plus `io.TextIOWrapper` in text mode) so `write()` returns `int`; SFTP backup retries rename collisions. FTP rejects `append=True` with `UnsupportedProtocolError`. When `show_progress=True`, wraps the underlying binary stream in `_CountingWriteStream` and initializes `tqdm(total=None, initial=initial_bytes, unit='B', unit_scale=True)` after wrapping the codec so header bytes written during `open()` are counted once.
- **`write(data) -> int`**, **`writelines(lines) -> None`**, **`flush() -> None`**: Write data and flush buffered output (and pending progress bytes when `show_progress=True`); raise `ValueError` when closed. In text mode (`binary=False`), `write(data)` accepts `str` and returns the number of characters written, and `writelines(lines)` accepts an iterable of `str`. In binary mode (`binary=True`), `write(data)` accepts `bytes`-like objects and returns the number of bytes written, and `writelines(lines)` accepts an iterable of `bytes`-like objects (calling `self._fh.write(line)` per item so `ZstdCompressionWriter` matches stdlib binary writers). Neither `writelines()` mode inserts line separators automatically. When `write` is not overridden by a subclass, `open()` binds `self.write` directly to `self._fh.write`.
- **`close() -> None`**: Deterministically and idempotently closes `self._fh` first (flushing buffered text and compressed trailer bytes through `_CountingWriteStream` while the progress callback is active), flushes any remaining batched progress delta (catching `BaseException`), detaches the callback, and closes all remaining raw, transport, and `tqdm` handles without double-closing.

## Package Exports (`openas.__all__`)

`openas.__all__` exports `openas`, `OpenAsReader`, `OpenAsWriter`, `OpenAsError`, `UnsupportedArchiveError`, `ReadOnlyProtocolError`, `UnsupportedProtocolError`, `__version__`, and `__author__`. Internal `FTPSessionWrapper` is not part of the top-level package API (`openas.openas` retains lazy PEP 562 resolution for internal use).
